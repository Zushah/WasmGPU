# createSplatField#externalColorBufferSrgb

## Summary

`createSplatField#externalColorBufferSrgb` reports whether rendering decodes a packed external direct-color buffer from sRGB.

## Syntax

```ts
readonly SplatField.externalColorBufferSrgb: boolean
```
