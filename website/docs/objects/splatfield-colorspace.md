# SplatField.colorSpace

## Summary

`SplatField.colorSpace` reports whether direct colors or spherical-harmonic color data are interpreted as `"linear"` or `"srgb"`. It is selected at construction.

## Syntax

```ts
readonly SplatField.colorSpace: "linear" | "srgb"
```
