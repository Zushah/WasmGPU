# createGlyphField#markUniformsDirty

## Summary
createGlyphField#markUniformsDirty marks the packed visual/scale uniform payload for rewrite without changing instance data.

## Syntax
```ts
GlyphField.markUniformsDirty(): void
glyphField.markUniformsDirty();
```
