# createLatticeSpace#getUniformData

## Summary

`createLatticeSpace#getUniformData()` packs dimensions, layout, draw range, color mode, opacity, scale transform, and custom stops for rendering.

## Syntax

```ts
LatticeSpace.getUniformData(): Float32Array
```

## Returns

`Float32Array` - A newly allocated uniform payload.
