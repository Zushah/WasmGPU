# LatticeSpace.blendMode

## Summary

`LatticeSpace.blendMode` controls opaque or transparent blending for cell rendering.

## Syntax

```ts
LatticeSpace.blendMode: BlendMode
```

## Notes

Transparent 3D lattices sort visible cell centers by camera depth.
