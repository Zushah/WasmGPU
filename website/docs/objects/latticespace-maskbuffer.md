# LatticeSpace.maskBuffer

## Summary

`LatticeSpace.maskBuffer` exposes the current optional cell-mask GPU storage buffer, or `null`.

## Syntax

```ts
LatticeSpace.maskBuffer: GPUBuffer | null
```
