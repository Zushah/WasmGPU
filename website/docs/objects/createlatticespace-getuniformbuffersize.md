# createLatticeSpace#getUniformBufferSize

## Summary

`createLatticeSpace#getUniformBufferSize()` returns the byte size of the packed lattice uniform payload.

## Syntax

```ts
LatticeSpace.getUniformBufferSize(): number
```

## Returns

`number` - `368`, the byte size of the packed lattice uniform payload.
