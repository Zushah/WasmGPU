# LatticeSpace.getLocalBounds

## Summary

`LatticeSpace.getLocalBounds()` analytically bounds cells in `indexRange` using `origin`, `spacing`, and `cellScale`.

## Syntax

```ts
LatticeSpace.getLocalBounds(): Bounds3
```
