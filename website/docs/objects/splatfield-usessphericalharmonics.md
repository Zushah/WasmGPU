# SplatField.usesSphericalHarmonics

## Summary

`SplatField.usesSphericalHarmonics` reports whether the active color source contains spherical-harmonic coefficients rather than direct RGBA colors.

## Syntax

```ts
readonly SplatField.usesSphericalHarmonics: boolean
```

## Notes

Direct colors and spherical-harmonic sources are mutually exclusive.
