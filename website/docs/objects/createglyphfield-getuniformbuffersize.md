# createGlyphField#getUniformBufferSize

## Summary
createGlyphField#getUniformBufferSize returns the fixed 240-byte size of the 60-float glyph uniform payload.

## Syntax
```ts
GlyphField.getUniformBufferSize(): number
const result = glyphField.getUniformBufferSize();
```

## Returns
`240`
