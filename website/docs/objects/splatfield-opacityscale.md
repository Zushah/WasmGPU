# SplatField.opacityScale

## Summary

`SplatField.opacityScale` is a non-negative multiplier applied to every splat's stored opacity. Assigning a negative value clamps it to zero.

## Syntax

```ts
SplatField.opacityScale: number
splatField.opacityScale = 0.75;
```
