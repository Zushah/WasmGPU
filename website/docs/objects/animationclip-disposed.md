# AnimationClip.disposed

## Summary
AnimationClip.disposed reports whether `dispose()` has released the clip's owned Wasm allocations and invalidated sampling and pointer access.

## Syntax
```ts
AnimationClip.disposed: boolean
```

## Returns
`boolean`
