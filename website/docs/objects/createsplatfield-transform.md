# createSplatField#transform

## Summary

`createSplatField#transform` is the field's mutable local-to-world transform. Scene bounds and rendering use its world matrix.

## Syntax

```ts
SplatField.transform: Transform
```

## Returns

`Transform` - The transform owned by this field.
