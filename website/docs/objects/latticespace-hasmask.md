# LatticeSpace.hasMask

## Summary

`LatticeSpace.hasMask` reports whether an optional cell-activity mask is available.

## Syntax

```ts
readonly LatticeSpace.hasMask: boolean
```

## Notes

A zero mask value makes the corresponding cell inactive.
