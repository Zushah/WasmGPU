# Skin.jointIndicesPtr

## Summary
Skin.jointIndicesPtr returns the pointer to `jointCount` packed `u32` transform indices in Wasm memory. Access after `dispose()` throws.

## Syntax
```ts
Skin.jointIndicesPtr: WasmPtr
```

## Returns
`WasmPtr`
