# LatticeSpace.colorSpace

## Summary

`LatticeSpace.colorSpace` selects whether direct RGBA cell data is interpreted as `"linear"` or `"srgb"`.

## Syntax

```ts
LatticeSpace.colorSpace: "linear" | "srgb"
```
