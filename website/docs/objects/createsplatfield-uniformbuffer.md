# createSplatField#uniformBuffer

## Summary

`createSplatField#uniformBuffer` exposes the renderer-managed uniform buffer, or `null` before renderer initialization.

## Syntax

```ts
SplatField.uniformBuffer: GPUBuffer | null
```
