# LatticeSpace.componentCount

## Summary

`LatticeSpace.componentCount` is the immutable number of stored values per cell.

## Syntax

```ts
readonly LatticeSpace.componentCount: 1 | 2 | 3 | 4
```

## Notes

`colorMode: "rgba"` requires exactly four components.
