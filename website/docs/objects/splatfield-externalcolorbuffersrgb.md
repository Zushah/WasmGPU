# SplatField.externalColorBufferSrgb

## Summary

`SplatField.externalColorBufferSrgb` reports whether a packed external direct-color buffer is decoded from sRGB by the shader.

## Syntax

```ts
readonly SplatField.externalColorBufferSrgb: boolean
```
