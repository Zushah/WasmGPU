# LatticeSpace.solidColor

## Summary

`LatticeSpace.solidColor` is the RGBA color used by `"solid"` color mode.

## Syntax

```ts
LatticeSpace.solidColor: [number, number, number, number]
```

## Notes

The getter and setter copy the four-component value.
