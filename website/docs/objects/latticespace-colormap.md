# LatticeSpace.colormap

## Summary

`LatticeSpace.colormap` selects a built-in colormap name, `"custom"`, or a `Colormap` object for scalar rendering.

## Syntax

```ts
LatticeSpace.colormap: LatticeSpaceColormap | Colormap
```
