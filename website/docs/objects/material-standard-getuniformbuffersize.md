# material.standard#getUniformBufferSize

## Summary
material.standard#getUniformBufferSize returns `816`, the byte size of the material's 204-float data block.

## Syntax
```ts
StandardMaterial.getUniformBufferSize(): number
const result = material.getUniformBufferSize();
```

## Returns
`number` - Always `816`.
