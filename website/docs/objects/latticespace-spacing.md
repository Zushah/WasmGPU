# LatticeSpace.spacing

## Summary

`LatticeSpace.spacing` sets the positive center-to-center distance between cells on each axis.

## Syntax

```ts
LatticeSpace.spacing: [number, number, number]
```

## Notes

All components must be finite and greater than zero.
