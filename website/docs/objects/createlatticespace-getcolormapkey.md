# createLatticeSpace#getColormapKey

## Summary

`createLatticeSpace#getColormapKey()` returns an opaque string identifying the active colormap configuration. Equal keys identify the same configuration; do not parse or persist their format.

## Syntax

```ts
LatticeSpace.getColormapKey(): string
```
