# LatticeSpace.bindGroupKey

## Summary

`LatticeSpace.bindGroupKey` is the renderer cache key for the currently bound resources. Resource changes reset it to `null`.

## Syntax

```ts
LatticeSpace.bindGroupKey: string | null
```
