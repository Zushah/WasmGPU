# createScene#visibleLatticeSpaces

## Summary

`createScene#visibleLatticeSpaces` returns the attached lattice spaces whose `visible` property is `true`.

## Syntax

```ts
Scene.visibleLatticeSpaces: LatticeSpace[]
const visible = scene.visibleLatticeSpaces;
```

## Returns

`LatticeSpace[]` - A newly filtered array in insertion order.
