# World

The world subsystem contains scene-level APIs: cameras, lights, overlays, and scene traversal utilities for meshes, pointclouds, glyphfields, nodelinks, splatfields, and latticespaces.

## In This Section

- Perspective and orthographic camera workflows
- Ambient, directional, point, and spot light APIs
- Overlay systems (grid, legend, axis triad)
- Scene query, bounds, and traversal helpers
- Visibility-oriented scene inspection
