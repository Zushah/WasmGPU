# WasmGPU.math.vec3.reflect

## Summary
WasmGPU.math.vec3.reflect reflects an incident vector about a normal-like direction. Use it for bounce directions and mirror responses.

## Syntax
```ts
WasmGPU.math.vec3.reflect(v1: number[], v2: number[]): number[]
const result = wgpu.math.vec3.reflect(v1, v2);
```

## Parameters
| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `v1` | `number[]` | Yes | First vector input as `[x, y, z]`. |
| `v2` | `number[]` | Yes | Second vector input as `[x, y, z]`. |

## Returns
`number[]` - New 3D vector as `[x, y, z]`.

## Type Details
```ts
type Vec3 = number[]; // expected length: 3 ([x, y, z])
```

## Example
```js
const canvas = document.querySelector("canvas");
const wgpu = await WasmGPU.create(canvas);

const v1 = [1, -1, 0.5];
const v2 = [0, 1, 0];
const result = wgpu.math.vec3.reflect(v1, v2);
console.log(result);
```
