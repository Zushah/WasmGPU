# Scene.visibleSplatFields

## Summary

`Scene.visibleSplatFields` returns the attached splat fields whose `visible` property is `true`.

## Syntax

```ts
Scene.visibleSplatFields: SplatField[]
const visible = scene.visibleSplatFields;
```

## Returns

`SplatField[]` - A newly filtered array in insertion order.
