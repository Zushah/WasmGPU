# GlyphField.clearWasmSources

## Summary

`GlyphField.clearWasmSources()` detaches all borrowed `WasmMemoryView` channels without freeing their WebAssembly allocations.

## Syntax

```ts
GlyphField.clearWasmSources(): void
```
