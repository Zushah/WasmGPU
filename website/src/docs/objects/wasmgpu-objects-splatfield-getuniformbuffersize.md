# SplatField.getUniformBufferSize

## Summary

`SplatField.getUniformBufferSize()` returns the byte size required for this object's renderer uniform block.

## Syntax

```ts
SplatField.getUniformBufferSize(): number
```

## Returns

`number` - `16` bytes in v0.9.0.
