# SplatField.shBuffer

## Summary

`SplatField.shBuffer` exposes the current spherical-harmonic coefficient GPU storage buffer, or `null` when direct colors are active.

## Syntax

```ts
SplatField.shBuffer: GPUBuffer | null
```
