# LatticeSpace.uniformBuffer

## Summary

`LatticeSpace.uniformBuffer` exposes the renderer-managed uniform buffer, or `null` before initialization.

## Syntax

```ts
LatticeSpace.uniformBuffer: GPUBuffer | null
```
