# LatticeSpace.getWorldBounds

## Summary

`LatticeSpace.getWorldBounds()` transforms the analytic local bounds by `transform.worldMatrix`.

## Syntax

```ts
LatticeSpace.getWorldBounds(): Bounds3
```
