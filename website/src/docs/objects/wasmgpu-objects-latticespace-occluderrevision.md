# LatticeSpace.occluderRevision

## Summary

`LatticeSpace.occluderRevision` changes when state affecting opaque coverage changes, allowing previous-frame occlusion data to be invalidated safely.

## Syntax

```ts
readonly LatticeSpace.occluderRevision: number
```
