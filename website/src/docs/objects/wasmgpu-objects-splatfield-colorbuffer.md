# SplatField.colorBuffer

## Summary

`SplatField.colorBuffer` exposes the current packed direct-color GPU storage buffer, or the fallback color buffer used with some source configurations.

## Syntax

```ts
SplatField.colorBuffer: GPUBuffer | null
```
