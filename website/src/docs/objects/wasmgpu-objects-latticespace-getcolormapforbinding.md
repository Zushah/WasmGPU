# LatticeSpace.getColormapForBinding

## Summary

`LatticeSpace.getColormapForBinding()` resolves the built-in, custom-stop, or explicit `Colormap` object to bind for rendering.

## Syntax

```ts
LatticeSpace.getColormapForBinding(): Colormap
```
